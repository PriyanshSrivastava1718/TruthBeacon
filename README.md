# TruthBeacon

### Guided by Evidence. Driven by Truth.

TruthBeacon is an **Explainable AI-based Fact Verification Platform** designed to help users analyze and verify potentially misleading claims using an evidence-first approach.

Instead of simply returning a **True / False** classification, TruthBeacon aims to provide supporting evidence, trusted source references, confidence levels, verification timestamps, and clear explanations behind its conclusions.

---

## 🎯 Problem 

With the rapid growth of social media, messaging platforms, online news, and AI-generated content, misinformation can spread rapidly.

Users may encounter unverified claims through:

- Text messages
- Websites and URLs
- PDF documents
- Screenshots
- Shared links

Existing AI chatbots and fact-checking tools may provide answers or classifications without enough transparency about the evidence behind their conclusions.

TruthBeacon aims to make the verification process more **transparent, evidence-based, and explainable**.

---

## 💡 Proposed Solution

TruthBeacon follows an **evidence-first verification pipeline**:

User Input

Claim Extraction
